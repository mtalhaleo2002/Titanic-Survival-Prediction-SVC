## Dataset Information

The project uses the Titanic passenger dataset provided by DigiSkills LMS.

**Dataset URL:**

https://lms.digiskills.pk/Courses/AIP301/Downloads/titanic.csv

The dataset used in this exercise contains 418 passenger records and 12 columns.

### Dataset Features

| Feature | Description |
|---------|-------------|
| PassengerId | Unique passenger identifier |
| Survived | Target variable: 0 = Not Survived, 1 = Survived |
| Pclass | Passenger class (1, 2, 3) |
| Name | Passenger name |
| Sex | Gender |
| Age | Passenger age |
| SibSp | Siblings/spouses aboard |
| Parch | Parents/children aboard |
| Ticket | Ticket number |
| Fare | Ticket fare |
| Cabin | Cabin information |
| Embarked | Port of embarkation |

**Dataset limitation:** The 418-row file matches the structure of the commonly used Titanic test dataset with derived survival labels. Therefore, classification accuracy on this dataset should not be treated as a reliable real-world Titanic survival benchmark.

## Task 3 — Data Cleaning

### Objective

Identify and handle missing values in the Titanic dataset.

### Operations Performed

1. Count missing values in each column.
2. Fill missing numerical values using the median.
3. Fill missing categorical values using the mode.
4. Replace missing cabin information with `Unknown`.
5. Verify that missing values have been handled.
6. Save the cleaned dataset.

### Output

```text
data/titanic_cleaned.csv
```

The cleaned dataset is used for subsequent visualization.

For model evaluation, preprocessing is independently fitted on the training split to reduce data leakage.

Build and evaluate a Support Vector Classifier model for predicting passenger survival.

### Target Variable

### Independent Features

### Machine Learning Workflow

1. Identify dependent and independent variables.
2. Split the dataset into training and testing sets.
3. Handle missing values within the preprocessing pipeline.
4. Scale numerical variables.
5. One-hot encode categorical variables.
